# Contributor Covenant Code of Conduct

## Our Pledge

We want Percolume to be a welcoming project for people with different backgrounds, experience levels, and ways of working. Participants are expected to help make the project useful, calm, and constructive.

## Expected Behavior

- Be respectful and patient.
- Explain disagreement with evidence and concrete examples.
- Welcome corrections and ask questions in good faith.
- Keep discussions focused on the project and its users.
- Protect private progress data, notes, screenshots, and exported files.

## Unacceptable Behavior

Harassment, personal attacks, discrimination, intimidation, unwanted contact, sexualized language, publishing private information, and deliberately disruptive behavior are not acceptable.

## Enforcement

Please report problems privately to the repository maintainers. Reports should include what happened, where it happened, and any relevant links. Maintainers may remove content, limit participation, or close discussions when needed to protect the community.

This code applies to repository spaces and project-related events.
